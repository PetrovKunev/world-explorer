# База данни — структура на скриптовете

| Място | Предназначение |
|---|---|
| `schema.sql` | Пълната схема за **нова инсталация**: таблица `destinations`, индекси, RLS политики, тригер за `updated_at`. Изпълнява се веднъж в Supabase SQL Editor. |
| `storage-setup.sql` | Настройка на Storage bucket-а за снимки. |
| `migrations/NNN_*.sql` | Номерирани миграции за **съществуваща** база — изпълняват се по ред. Безопасни са за повторно изпълнение. |
| `archive/` | Исторически еднократни скриптове, вече приложени. Пазят се само за справка — не ги изпълнявайте. |

Нова миграция: добавете файл `migrations/00N_кратко-име.sql` със следващия
пореден номер и отразете промяната и в `schema.sql`, така че двата пътя
(нова инсталация / миграция) да водят до еднаква схема.
